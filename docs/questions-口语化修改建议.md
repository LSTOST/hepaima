# 题目中不够口语化的表达 · 修改建议

以下按「原文 → 更口语」列出，便于批量替换或按题修改。

---

## 一、题干里常见的书面腔

| 原文 | 更口语 |
|------|--------|
| 你更会？ / 你更倾向于？ | 你会咋样？ / 你一般会咋办？ |
| 你通常会？ | 你一般会？ / 你会怎么做？ |
| 你的第一反应是？ | 你第一反应是啥？ / 你当时会咋想？ |
| 你理想中和对方的关系是？ | 你心里觉得两个人最好啥样？ |
| 长期相处中，你更看重…… | 在一起久了，你更看重…… |
| 稳定期里，你和朋友…… | 到了稳定期/在一起久了，你和朋友…… |
| 双方对「……」意见不同时？ | 俩人在这事上想法不一样时？ |
| 讨论……时，你更倾向于？ | 聊到……时，你一般会？ |
| 家务分工上，你们的做法更接近？ | 家务你们一般是咋分的？ / 谁干活你们更像哪种？ |
| 表达好感时，你更倾向于？ | 对对方好的时候，你更常咋做？ |
| 表达爱意时，你更习惯？ | 示好的时候，你更习惯？ |

## 二、选项里偏书面/问卷腔

| 原文 | 更口语 |
|------|--------|
| 付诸行动 | 真的去做了 / 记着并做到了 |
| 彼此信任、有空间也有关心 | 互相信任，有各自空间又互相惦记 |
| 尊重对方的选择 | 看对方想怎样就怎样 / 随对方 |
| 达成共识 | 说好了 / 聊拢了 / 想法一致 |
| 一起理性分析，列出利弊再决定 | 一起想想利弊、摊开说清楚再定 |
| 各退一步，找个折中方案 | 各让一步，取个中间 / 折中一下 |
| 折中方案 | 折中一下 / 取中间 |
| 展现脆弱的一面 | 在对方面前哭/说压力大/露怯 |
| 肢体上的亲近 | 抱一下、搂一下 / 肢体接触 |
| 主动报备行程、分享日常 | 到哪了会说一声、会分享日常 |
| 冷静下来后你通常？ | 冷静下来之后你一般会咋办？ |
| 需要对方给我安心 | 需要对方让我安心 / 给我吃定心丸 |
| 暂时回避 | 先不提 / 先搁着 |
| 在计划中或已提上日程 | 在打算了 / 已经排上日程了 |
| 主动复盘，说说各自感受 | 会事后拿出来聊聊、说说各自咋想的 |
| 传达双方想法 | 在中间传个话 / 两边都说说 |
| 情绪平复后 | 气消了以后 / 冷静下来以后 |
| 理性讨论利弊 | 一起摊开说说利弊 |
| 共同做决定 | 一起定 / 一块儿决定 |
| 做法更接近？ | 你们更像哪种？ / 你们一般是咋样？ |

## 三、按题目逐条（高优先级）

### 暧昧期

- **题4 选项**：「说明对方想让我走进对方的生活」→「说明对方想让我融入他的生活」或保留，略书面可接受。
- **题5 题干**：「展现脆弱的一面」→「在对方面前哭、说压力大、露怯」。
- **题13 选项**：「并付诸行动」→「并真的去做了」或「记着并做到了」。
- **题16 选项**：「肢体上的亲近」→「先抱一下、搂一下」。
- **题19 选项**：「主动分享日常、到哪了在干嘛」→「会跟我说到哪了、在干嘛、日常琐事」。
- **题20 题干**：「表达好感时，你更倾向于？」→「对对方好的时候，你更常咋做？」。
- **题23 选项**：「会和另一半认真讨论，达成共识」→「会和另一半好好聊，聊拢了再说」。
- **题24 选项**：「暂时回避」→「先不提 / 先搁着」。
- **题28 选项**：「各退一步，找个折中方案」→「各让一步，取个中间」；「更倾向于？」→「你一般会？」。

### 热恋期

- **题3**：「会主动沟通，希望尽快和好」→「会主动找对方聊，想快点好」。
- **题22 选项**：「找个合适的时机，直接说出自己的想法」→「找机会直接说咋想的」；「希望对方自己能察觉到」→「希望对方自己能感觉到」。
- **题23 选项**：「一起理性分析，列出利弊再决定」→「一起想想利弊，摊开说清楚再定」；「你更倾向于？」→「你一般会？」。
- **题25 选项**：「是感情的归宿，遇到对的人就会想结」→ 可保留或改为「遇到对的人就想结」。
- **题26 选项**：「达成共识」→「说好了 / 聊拢了」；「暂时回避」→「先不提」。
- **题31 选项**：「各退一步，找个折中方案」→「各让一步，取个中间」；「更倾向于？」→「你一般会？」。
- **题33 选项**：「会一起规划，大额支出会商量」→「会一起打算，大笔钱会商量」；「还没深入聊过」→「还没细聊过」。

### 稳定期

- **题2 题干**：「长期相处中」→「在一起久了」。
- **题4 选项**：「愿意一起推进，也会和对方商量节奏」→「愿意一起往前推，也会和对方商量节奏」；「会试探对方的想法」→「会探探对方咋想」。
- **题9 题干**：「稳定期里」→「在一起久了 / 到了稳定期」。
- **题11 题干**：「你理想中「稳定期的关系」是？」→「你心里觉得稳定期两个人最好啥样？」。
- **题24 选项**：「一起分析利弊，共同做决定」→「一起摊开说利弊，一块儿定」；「你更倾向？」→「你一般会？」。
- **题27 选项**：「有共识，在计划中或已提上日程」→「说好了，在打算了或已经排上日程」。
- **题29 选项**：「还没深入聊」→「还没细聊」；「暂时回避甚至可能谈不拢」→「先搁着，甚至可能谈不拢」。
- **题31 题干**：「你们的做法更接近？」→「你们更像哪种？」。
- **题33 选项**：「主动复盘，说说各自感受，避免下次」→「会事后拿出来聊聊，说说各自咋想的，下次少吵」。
- **题34 选项**：「在中间调解，传达双方想法」→「在中间传话，两边都说说」。
- **题35 选项**：「等情绪平复后，好好谈一次」→「气消了以后好好谈一次」。
- **题39 选项**：「和对方聊聊自己的感受，一起想想怎么挤出时间相处」→「会和对方说说自己的感受，一起想想咋挤出时间」；「用冷战或吵架让对方知道我不满」→「用冷战或吵架让对方知道我不爽」。
- **题40 题干**：「双方对……意见不同时？」→「俩人在这事上想法不一样时？」；「理性讨论利弊，找折中方案」→「摊开说利弊，找个折中的办法」。
