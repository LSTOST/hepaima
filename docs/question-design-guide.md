# 合拍吗 · 题目设计指南

> 目标：让题目更有代表性、更接地气、更容易让人产生代入感，通过真人情侣测试反复迭代。

---

## 一、现有题目容易「不接地气」的原因

1. **阶段错位**  
   暧昧期用了「伴侣」「吵架」「见爸妈」「纪念日」等已确立关系后的说法和场景，暧昧期用户会感觉「我们还没到那一步」。

2. **情境太抽象**  
   题干像在描述一种类型（「当伴侣一段时间没回你消息时」），缺少时间、场合、细节，用户难以立刻脑补「我上次就遇到过」的画面。

3. **选项偏「正确」或极端**  
   选项里「主动沟通」「各退一步」等偏理想化，真实反应（如「会憋着但心里不爽」「会阴阳两句」）没有出口，选不出真实自我。

4. **阶段间重复**  
   热恋期和暧昧期有大量题干完全相同的题，只是 stage 不同，没有体现「热恋期专属」的典型情境（同居初磨合、激情与习惯的平衡、开始谈未来等）。

---

## 二、情境化设计原则

### 1. 用「具体情境」代替「抽象描述」

- **不好**：当伴侣一段时间没回你消息时，你通常会？  
- **更好**：晚上你发了条微信，TA 过了两三个小时还没回，你通常会？（暧昧期可改为：你发了一条，TA 一直「正在输入」又没发出来，你更会？）

把「谁、什么时候、发生了什么」写清楚，让人一眼能代入。

### 2. 阶段专属称呼与场景

| 阶段   | 称呼建议           | 场景范围 |
|--------|--------------------|----------|
| 暧昧期 | TA / 对方 / 他·她  | 还没确定关系：试探、揣测、谁主动、回消息节奏、约出来、是否官宣、吃醋但没资格说 |
| 热恋期 | 伴侣 / TA          | 已在一起：约会日常、同居初期的摩擦、见家长、花钱、未来规划、激情与习惯的平衡 |
| 稳定期 | 伴侣 / TA          | 长期相处：倦怠、分工、两家人的事、过年回谁家、要孩子、父母同住、工作与陪伴 |

暧昧期避免「伴侣」「吵架」「纪念日」等已确立关系用语；稳定期可以多写「两家」「过年」「孩子」「同住」等具体议题。

### 3. 选项要覆盖「真实反应」

除了「好好沟通」「各退一步」，要留出：
- 会憋着但心里不爽  
- 会阴阳/开玩笑式表达  
- 等对方先开口  
- 装作没事但记着  

让用户能选到「我平时真的会这样」的选项，而不是选「我应该这样」。

### 4. 一题一事、一题一景

一道题只问一个具体情境，不混搭多种情况。例如：「TA 回消息很慢」和「TA 和异性单独吃饭」拆成两题，更易代入。

## 三、三阶段专属情境清单（出题时可直接取材）

### 暧昧期（还没确定关系）

- **联系与回应**：发消息 TA 回得慢 / 已读不回 / 经常「正在输入」又不发；谁更常主动找对方；会不会盯着 TA 的在线状态或朋友圈。
- **邀约与试探**：谁主动约见面；约好了又改期/放鸽子你怎么想；想见又不敢说；会不会故意冷淡看 TA 反应。
- **边界与吃醋**：TA 和别的异性走得近你什么感觉；会不会翻 TA 社交动态；想确认关系又怕开口。
- **表达与心意**：更看重 TA 说什么还是做什么；TA 没表示时你会不会暗示或追问；节日/生日 TA 没表示你的反应。
- **暧昧期不写**：正式吵架、见家长、纪念日、同居、谁管钱、要不要孩子。（这些留给热恋/稳定期。）

### 热恋期（已在一起，激情尚在）

- **日常相处**：约会谁安排、吃什么玩什么谁定；对方一直看手机你怎么办；周末想腻在一起还是各留空间。
- **关系推进**：见家长/见朋友谁先提、你紧不紧张；开始聊结婚/买房/未来时你的态度。
- **冲突与和好**：因为小事闹不愉快后谁先开口；对方说了让你不舒服的话你怎么反应；约会计划临时有变你的情绪。
- **爱与表达**：你更吃「说出来的爱」还是「做出来的」；生病/低落时希望 TA 怎么对你；纪念日/生日你更看重什么。
- **生活习惯初磨合**：家务、作息、花钱方式开始有分歧时你怎么处理。

### 稳定期（长期相处、过日子）

- **倦怠与新鲜感**：感觉淡了/没话说了你会怎么办；对方忙工作经常忽略你你的反应。
- **两家人的事**：过年回谁家；和对方父母有矛盾你站哪边；要不要和父母同住。
- **重大决策**：买房、结婚、要孩子、谁管钱；意见不一致时怎么谈。
- **日常分工**：家务、带孩子（若已有）、谁决定吃什么去哪玩；对方「变了」你委屈时怎么反应。

## 四、如何用真人测试迭代

1. **小样本深度访谈**  
   找 5–10 对真人情侣（每阶段 2–3 对），让他们边做题边出声想：「这道题你第一时间想到的是哪次经历？」  
   若多数人想不出具体经历，说明情境不够具体或阶段不对。

2. **追问**  
   「你上次遇到类似情况是什么时候？当时你实际怎么做的？」  
   把他们的原话整理成新选项，再反哺题目。

3. **选项分布看「有没有人选」**  
   若某选项几乎没人选，可能是表述不清或不符合真实反应；若某选项比例异常高，可能是社会赞许偏差，可考虑改表述或拆题。

4. **A/B 测试题干**  
   同一维度（如依恋）保留计分逻辑，只换题干和选项文案，对比完成率、答题时长、结果与自评一致性。

## 五、示例：从抽象到情境化

**原题（偏抽象）**  
「当伴侣一段时间没回你消息时，你通常会？」  
选项：继续忙自己的 / 再发一条问问 / 胡思乱想 / 理解但希望忙完说一声  

**暧昧期情境化改写**  
「你发了条微信，TA 过了两三个小时还没回，你更会？」  
- 继续忙自己的，等 TA 有空自然会回  
- 有点急，会再发一条或打个岔问问在干嘛  
- 会想是不是自己说错话了、TA 在躲着自己  
- 理解可能在忙，但希望 TA 忙完能回一句，不然心里不踏实  

**热恋期情境化改写**  
「晚上你发了条消息，TA 一直没回，第二天早上才回说昨晚睡着了，你更会？」  
- 没事，下次要是先睡可以说一声就好  
- 会有点失落，希望 TA 以后能睡前说一声  
- 会有点不高兴，觉得 TA 不够在意自己  
- 表面没事，心里会记着，下次 TA 找你你也晚点回  

这样同一维度（依恋/安全感）的计分逻辑可以不变，只替换题干和选项文案，便于逐步替换整库题目。

## 六、落地顺序建议

1. **先改暧昧期**  
   暧昧期错位最明显（用「伴侣」等），优先把暧昧期题目全部改成「TA/对方」+ 暧昧专属情境，并保证选项有「真实反应」。  

2. **再区分热恋期**  
   热恋期减少与暧昧期完全重复的题干，增加「已在一起」后的专属情境（见家长、同居初磨合、谈未来、约会计划有变等）。  

3. **最后打磨稳定期**  
   稳定期题目相对已较贴阶段，重点把抽象题改成「具体到能脑补画面」的情境（如具体到「过年回谁家」「和父母同住」）。  

4. **每批改完都做一轮真人测试**  
   用上述访谈 + 选项分布 + 自评一致性做验证，再决定下一批替换哪些题。

## 七、争议性题目的使用（讨论感 × 传播）

### 适不适合加？

**适合。** 适度加入「有争议、无标准答案」的题目可以：
- 让用户和伴侣选完更想对比、讨论，提升互动和分享动机；
- 在社交媒体上更容易被转发、评论（「你们选的不一样！」「这道题我们吵了一晚上」）；
- 和「契合度测评」的定位不冲突——争议题本身就是价值观/边界感的体现，可以纳入 values、conflict 等维度。

前提是：**争议要「可讨论」，不要「引战或冒犯」**。不涉及人身攻击、不站队对错，而是呈现不同选择、让情侣看到差异。

### 怎么选争议题？

| 优先考虑 | 尽量避免 |
|----------|----------|
| 彩礼/房子写谁名、婚后谁管钱 | 涉及性别/地域攻击的表述 |
| 该不该看对方手机、异性闺蜜 | 明显贬低某一方的选项 |
| 过年回谁家、要不要和父母同住 | 非情侣也能吵起来的纯社会议题 |
| 丁克 vs 要孩子、什么时候要 | 与关系阶段严重不符（如暧昧期问彩礼） |

原则：**有争议 + 和「我们俩合不合」强相关**，且选项里每种立场都有人真实会选。

### 怎么出题不翻车？

1. **题干中性**  
   不写「你觉得看对方手机对不对」，而写「伴侣不愿意给你看手机，你的第一反应是？」让选项承载不同立场。

2. **选项覆盖多种立场，不暗示「正确」**  
   A/B/C/D 里既有「必须看/信任就不看/看但不承认/无所谓」，而不是只有一个「正确做法」。

3. **结果页可强化讨论**  
   争议题可以单独在报告里做成「讨论点」：例如「这道题你们选得不一样，可以聊聊彼此在意的点」，而不是只给分数。

4. **阶段匹配**  
   彩礼、孩子、同住等放稳定期；看手机、异性朋友可放热恋期；暧昧期可轻量一点（如「你会不会翻 TA 朋友圈/动态」）。

### 可用的争议题示例（可纳入题库或单独「讨论卡」）

- **该不该看对方手机？**  
  题干：伴侣不愿意让你看 TA 的手机，你的第一反应是？  
  选项倾向：必须给看才安心 / 不看但希望 TA 主动说 / 无所谓信任就好 / 我会偷偷看。

- **彩礼/房子写谁名？**（稳定期）  
  题干：谈到结婚，双方对彩礼或房子写谁名字有分歧时，你更会？  
  选项倾向：一起谈清楚，写两人名 / 谁出钱谁做主，但要商量 / 我家必须怎样怎样 / 先搁置，谈不拢再说。

- **异性闺蜜/蓝颜**  
  题干：伴侣有一个关系很好的异性朋友（闺蜜/哥们），你会？  
  选项倾向：完全接受 / 接受但希望有边界 / 不太舒服，会提出来 / 坚决不接受。

- **过年回谁家**（已有类似题，可加强选项的「争议感」）  
  题干保持，选项可增加更具体的立场：轮流 / 各回各家 / 必须回我家/TA 家 / 接父母一起过，让差异更清晰便于讨论。

以上题目均可按现有 category（如 values、conflict）设计选项与计分，不影响主流程；若希望「只讨论、不计入总分」，也可在产品上做成「附加讨论题」或结果页的「延伸讨论」模块。
