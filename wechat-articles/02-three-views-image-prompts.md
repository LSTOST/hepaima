## 《三观不合到底指什么？》配图 Prompt

### 使用说明

- 建议工具：Nano Banana 2 / 其他中文支持好的文生图模型  
- 统一风格：极简、扁平、现代编辑风插画，抽象人物、无面孔、无文字  
- 比例建议：  
  - 封面图：宽幅（接近 16:9 或 2.35:1）  
  - 内文插图：正方形或略竖版（如 4:5）

---

## 1. 封面图 Prompt

**主题：用 5 个问题重新看“三观不合”**

```text
极简扁平风插画，画面中心是一对抽象的无面孔人形剪影，面对面而立，中间由一条细细的、发光的线相连，线条微微弯曲，既连接又有一点拉扯的感觉，象征关系和三观之间的微妙张力。背景是从柔和粉色到紫色的渐变，干净克制，带少量几何图形装饰，不喧宾夺主。整体气质现代、理性又带一点温度，偏心理学杂志封面风格。画面中不要出现任何文字和数字。
```

---

## 2. 内文插图一：钱观（问题一）

**对应段落：你们怎么花钱，和怎么谈钱？**

```text
极简扁平插画，一男一女两个抽象人形剪影，分别站在天平两侧，天平居中。天平左边的托盘上有礼物盒、咖啡杯、机票等象征享受当下的小图标；右边托盘上有房子轮廓、存钱罐、保险盾牌等象征安全和长期规划的图标。左边人物姿态更放松随性，右边人物姿态更紧绷稳重。色调以柔和的蓝绿和橙色对比，背景干净简洁，现代编辑风插画，没有表情细节，没有任何文字。
```

## 3. 内文插图二：生活节奏观（问题二）

**对应段落：你们各自想要的人生节奏是什么？**

```text
极简扁平插画，画面被一条对角线分成左右两部分。左侧是高楼林立的城市剪影，灯光密集，几个人形快速行走，象征高压快节奏生活；右侧是小房子、树、山和太阳的剪影，一个人物慢悠悠散步或坐着喝饮料，象征慢生活。分界线上站着一对抽象无面孔人形，略微朝向不同方向，仿佛在犹豫选择哪一边。左侧色调偏冷蓝紫，右侧色调偏暖橙绿色，整体画面干净、平衡，没有文字。
```

**对应段落：发生冲突时，你们各自的默认反应是什么？**

```text
极简扁平插画，一对抽象人形剪影背对背坐在画面中央，中间隔着一道竖直的锯齿状闪电图案，象征冲突和矛盾。左侧人物头上有一团对话气泡，里面是很多短横线和小弧线，象征不停说话和情绪爆发；右侧人物头上是一堵小墙或一扇紧闭的门的图标，象征冷战和封闭。背景使用柔和的灰蓝色和淡紫色渐变，整体克制、理性，现代编辑风插画，无五官细节，无任何文字。
```

## 5. 内文插图四：对「家」和关系的理解（问题四）

**对应段落：你们怎么理解「家」和「亲密关系」？**

```text
极简扁平插画，一个大房子轮廓位于画面中心，房子内部被一条柔和的竖线分成左右两半。左半部分有沙发、抱枕、落地灯等温馨元素，色调偏暖米色和橙色，象征“避风港”和安全感；右半部分有书桌、电脑、书籍、行李箱等元素，色调偏冷蓝紫，象征“各自的人生和成长”。房子前面站着一对抽象无面孔人形剪影，靠得很近，但姿态略有不同。整体画面象征感强、干净简洁，没有文字。
```

## 6. 内文插图五：底线与关键选择（问题五）

**对应段落：在关键选择上，你们各自的「底线」是什么？**

```text
极简扁平插画，一条道路从画面下方延伸到上方，在中间分成多条分叉路。每条分叉路的上方悬浮一个小图标：城市天际线、婴儿图标、戒指、飞机、行李箱、老房子和新房子等，象征换城市、要不要孩子、婚姻、异地、家庭等关键选择。道路起点处站着一对抽象无面孔人形剪影，一人身体微微偏向左侧的某条路，另一人微微偏向右侧，但两人仍紧挨在一起。色调以中性蓝紫和米色为主，画面现代、象征性强，无文字。
```

## 7. 统一风格要点（复用）

```text
- 人物：抽象、无面孔、圆润几何造型，不画具体五官
- 风格：扁平插画、极简、现代杂志感，适合心理学主题
- 背景：纯色或轻微渐变，可加少量几何纹理，但不要复杂场景
- 情绪：整体克制、理性中带一点温度，不要夸张夸大
- 质感：哑光、柔和，不要高光、写实或 3D 效果
- 重要：画面中不要出现任何文字、数字、英文字母或水印
```
